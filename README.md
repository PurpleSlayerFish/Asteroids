# Asteroids
## Описание
_Маленький пет проект в портфолио от апреля 2023 года давности (написан от руки без готовых фреймворков, но с самописным мини ECS)_
Уничтожайте астероиды и атакующие вас летающие тарелки, стреляя в них снарядами и мощным лазерным лучем.
Наберите как можно больше очков!

## Инструкция
- После скачивания требуется собрать ассет бандлы: Assets => Create Asset Bundles
- Игру запускать со сцены SplashScene.

## Управление
Space - Тяга
A/D - Влево/Вправо
J - Огонь
K - Лазер
Esc - Пауза
